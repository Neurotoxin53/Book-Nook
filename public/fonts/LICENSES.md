# Font licenses

The fonts in this directory were downloaded from Google Fonts for My Book Nook.
Each registry entry records its license and source. OFL fonts use the
[SIL Open Font License 1.1](https://openfontlicense.org); Roboto Mono uses the
[Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).

See `config/google-fonts.lock.json` for exact source URLs and SHA-256 hashes.
