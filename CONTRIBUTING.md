# Contributing

Use Node 22.13 or newer and pnpm 11. Run `pnpm check` before publishing.

Commit messages follow Conventional Commits, for example:

- `feat: add ISBN lookup`
- `fix: preserve edited review during re-import`
- `docs: update beta recovery guidance`

Product releases use SemVer. The version shown in Settings/About comes from
`package.json`; the numeric revision reported by Sites is deployment metadata,
not the product version.
